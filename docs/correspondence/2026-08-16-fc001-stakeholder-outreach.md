# FC-001 Stakeholder Outreach — 2026-08-16

**Related field case:** [FC-001 — Policy-Driving AI Evaluation Provenance](../field-cases/FC-001-policy-evaluation-provenance.md)  
**Subject:** `AI regulation should require reproducible measurement provenance`

## Purpose

This correspondence asked for technical review, criticism or referral to appropriate staff working on AI evaluation, measurement standards or science and technology policy.

The message did **not** allege fraud or intentional manipulation and did **not** request a predetermined political conclusion. Its central request was that AI capability numbers used to support consequential policy should carry sufficient measurement provenance to be independently interpreted and checked.

## Core question sent

> **What exactly produced the number?**

The correspondence argued that a model score may also depend on the evaluation harness or agent scaffold, network and tool access, retries and trial budgets, model checkpoint/version, grader configuration, excluded runs and access to reference information.

It linked the public source records:

- [anthropics/claude-code#86979](https://github.com/anthropics/claude-code/issues/86979) — benchmark measurement provenance;
- [anthropics/claude-code#87086](https://github.com/anthropics/claude-code/issues/87086) — applying the same provenance standard to policy-relevant evaluations.

## Good-faith falsifier included in the correspondence

The message explicitly stated that if independent strict-harness measurements reproduce the published results, the concern largely disappears and the regulatory case becomes stronger.

That condition is preserved as the falsifier for [FC-001](../field-cases/FC-001-policy-evaluation-provenance.md).
